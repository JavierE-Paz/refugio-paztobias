# refugio-paztobias
Este proyecto ayuda a crear objetos en este caso animales e interactuar de cierta forma con ellos

## Requisitos
- hay que tener instalado python
- hay que tener instalado pip

## Instalación
1. clonar el repositorio:
    git clone https://github.com/JavierE-Paz/refugio-paztobias.git

2. Entrar a la carpeta:
    cd refugio-paztobias

2. Instalar cowsay:
    pip install -r requirements.txt

## Ejecución

Para ejecutar el programa ejecutar el siguiente comando en la terminal:
    python main.py
